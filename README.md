# Varun Karkera — AI Engineer Portfolio

This is a static portfolio designed for GitHub Pages.

## Files

- `index.html` — complete portfolio (HTML, CSS, JavaScript in one file)
- `.nojekyll` — prevents Jekyll processing
- `README.md` — setup notes

## Deploy to GitHub Pages

1. Put these files in the root of `vkarkera.github.io`.
2. Commit and push to the `main` branch.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

The site should appear at:

https://vkarkera.github.io/

## Optional resume

If you want a Resume button, add your PDF to the repository root as:

`resume.pdf`

Then add a button/link in `index.html` pointing to `resume.pdf`.

The current version intentionally does not publish your phone number.
